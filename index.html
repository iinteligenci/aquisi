Radar inicial

O que testar primeiro

1. Conteúdo com intenção de compraOrgânico

Vídeo curto mostrando corte, textura e uso do produto; chamada para consultar os kits e pedir. Marcar o link para medir a origem.

2. Oferta de entradaConversão

Testar um combo simples com preço e condições verdadeiros. Calcular a margem antes de divulgar e comparar pedidos gerados.

3. Público comercialB2B

Separar uma campanha para hamburguerias, bares e restaurantes, com foco em aplicações do defumado no cardápio. Não misturar com a mensagem para consumidor final.

São hipóteses para testar, não dados de demanda confirmados. Priorize uma experiência de cada vez.

Medição manual simples

Registrar resultado

Depois de rodar uma campanha, registre quantos pedidos novos ela trouxe e a receita atribuída. Os dados ficam neste navegador.

Próxima etapa de automação

Depois de validar qual campanha gera pedidos, conectamos somente o necessário: Analytics para origem do tráfego, catálogo real para preço/estoque e uma integração oficial de mensagens se fizer sentido.
